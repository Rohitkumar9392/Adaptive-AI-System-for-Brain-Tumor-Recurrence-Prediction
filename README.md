# 🧠 Neuro Oncology Forecast: Brain Tumor Recurrence Prediction Using ML & DL

## 📖 Overview

Neuro Oncology Forecast is a machine learning and deep learning–based web application developed as a collaborative B.Tech major project. The system analyzes brain MRI images to assist in brain tumor prediction and provide AI-assisted clinical decision support through a Flask-based web interface.

## ✨ Features

- Brain MRI image analysis
- AI-powered brain tumor prediction
- Confidence score generation
- Flask-based web application
- Deep learning model integration
- User-friendly interface

## 🛠️ Tech Stack

- Python
- Flask
- TensorFlow
- Keras
- OpenCV
- NumPy
- Pandas
- HTML
- CSS

## Note

This project is developed for educational and research purposes as part of a B.Tech project.

The current implementation uses a pretrained YOLOv8 model to demonstrate the complete workflow of image upload, inference, visualization, and result presentation. The displayed tumor categories (Glioma, Meningioma, and Pituitary Tumor) are used for demonstration purposes and are not generated by a model specifically trained on brain MRI datasets.

For real-world clinical applications, the system should be trained and validated using a dedicated brain tumor MRI dataset and evaluated according to medical AI standards.
